## Deferred (minor)

1. `kg_render`: malformed YAML or a missing graph or README file crashes with a traceback and exit 1, instead of a `GraphError` and exit 2.
2. `kg_render`: node ids are not validated; ids with spaces or Mermaid keywords (`end`, `subgraph`) render broken Mermaid.
3. The `kg-sync` pre-commit hook's `files:` filter misses `tools/kg_render.py` (CI still catches it).
4. The KG views never show external-to-doc `documented_in` edges, so runbook and free-tier doc nodes do not appear.
5. The KG milestone view shows a node delivered in two milestones under the first only.
6. `check_keys`: a non-JSON or wrong-shape 200 body, a non-ASCII key, or a UTF-16 `.env` crashes with a traceback. No key is printed.
7. `no_emoji`: nonexistent paths and directories given on the command line pass silently.
8. `no_emoji` flags some text symbols (U+2713, U+2605) and misses U+25FD and U+25FE; `splitlines()` shifts line numbers on form feed or U+2028.
9. Test gaps: the special-character label test lacks `/`; the key-never-printed test lacks the network-error case; `test_calibrate_eval` reads the shipped config by a working-directory-relative path.
10. `README.md` says pre-commit runs the same checks as CI, but pre-commit runs neither pyright nor pytest; the opening paragraph describes unbuilt features in the present tense.
11. `.gitignore` ignores `.env` but not `.env.*` variants.
12. CI checkout lacks `persist-credentials: false`; jobs lack `timeout-minutes`; the gitleaks `pull_request` path is untested until the first Dependabot PR.
13. Spec EC-61 names a CONTRIBUTING clean-room note that the M0 plan never scheduled.
