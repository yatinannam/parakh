# calibrate_eval

MIT wrapper code and a synthetic config, used to run Calibrate (`calibrate-agent`, CC-BY-SA-4.0) for the Task 1 evaluation. No Calibrate code is included here; the wrapper imports a copy installed separately inside WSL.
